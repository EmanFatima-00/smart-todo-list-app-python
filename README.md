# Smart To-Do List Desktop Application

A feature-rich To-Do List desktop application built using Python, Tkinter (GUI), and JSON.

### Features
- Task creation, updating & deletion (CRUD operations)
- Task completion tracking
- Priority & category management
- Due-date & overdue task detection
- Search, filtering & sorting
- Task statistics & progress tracking
- JSON-based data persistence
- Input validation & error handling
- User-friendly GUI with Dark/Light mode

### Tech Stack
- Python
- Tkinter (GUI)
- JSON
- File Handling

### How to Run
1. Clone this repository:
   git clone https://github.com/EmanFatima-00/smart-todo-list-app-python.git

2. Run the application:
   python todo_app.py
